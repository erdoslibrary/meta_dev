# 퍼즐 데이터
실제 퍼즐 데이터 주는 방법
폴더 하나에 담아 경로를 알려 주시거나 이 대화에 붙여 넣어 주세요. 저작 형태 그대로 주셔도 제가 옮깁니다. 스키마에 맞춰 다시 쓰실 필요는 없습니다.


puzzle_data/
├── puzzles.json     (퍼즐 전체)
├── space.txt        (공간 메모. 형식 자유)
├── baseline.txt     (오프라인 관찰 메모)
└── images/          (퍼즐 그림, NPC 이미지는 있으면)
퍼즐마다 필요한 것

항목	주의할 점
순서, 장소 사물	어느 사물에 있는 퍼즐인지
NPC	이름. 이미지는 나중에 줘도 됩니다
대화	문장별로 나누고, 단서가 든 문장을 표시해 주세요
그림 파일	파일 이름에 정답이 들어가도 에이전트에게는 보이지 않습니다
문제 텍스트	오프라인 원문 그대로
정답	1개만. 인정할 답이 여러 개면 알려 주세요
힌트	1개로 축약하고, 오답 몇 번째에 열지(1~4) 적어 주세요
다음 장소	지시문과 그 지시문이 가리키는 사물. 마지막 퍼즐은 없음
반응 대사 (선택)	오답, 정답 대사. 장소는 실제 방 이름으로 직접 쓰세요
공간 메모에 필요한 것

층 목록과 층별 격자 크기(가로, 세로 칸 수)
방 이름과 칸 범위 (예: 라운지 E1:H6)
사물의 이름, 칸, 사진 파일. 사진은 퍼즐과 상관없는 사물을 포함해 모든 사물에 1장 이상 필요하고, 첫 번째 사진은 퍼즐 표시가 없는 평소 모습으로 주세요. 설명은 비워 둬도 되고, 단서를 담아도 됩니다.
